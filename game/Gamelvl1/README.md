# ⬡ CyberShield Game — Level 1 (Full Stack)

A cybersecurity awareness game with Node.js + Express backend and MongoDB database integration.

---

## 📁 Project Structure

```
CyberShield_Game/
├── backend/
│   ├── controllers/
│   │   └── level1Controller.js   ← Business logic for each API route
│   ├── models/
│   │   └── Level1.js             ← Mongoose schema (MongoDB document shape)
│   ├── routes/
│   │   └── level1Routes.js       ← Express route definitions
│   ├── .env                      ← Environment variables (edit this!)
│   ├── package.json              ← Backend dependencies
│   └── server.js                 ← Express app entry point
│
└── frontend/
    └── index.html                ← Game UI (updated with API calls)
```

## 🚀 Setup Instructions

### Step 1 — Install backend dependencies

```bash
cd backend
npm install
```

### Step 2 — Configure environment variables

Open `backend/.env` and set your values:

```env
# For local MongoDB (no account needed):
MONGO_URI=mongodb://localhost:27017/cybershield

# For MongoDB Atlas (cloud):
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/cybershield

PORT=5000
ENVIRONMENT=development
```

> **Tip:** If you don't have MongoDB installed locally, you can get a free cloud database at https://www.mongodb.com/atlas

### Step 3 — Start the backend server

```bash
# From the backend/ folder:
npm start

# Or, for auto-restart on file changes (development):
npm run dev
```

You should see:
```
✅  MongoDB connected successfully
🚀  Server running at http://localhost:5000
```

### Step 4 — Open the frontend

Simply open `frontend/index.html` in your browser.

> **Option A** — Double-click the file to open it directly.
>
> **Option B** — Serve it with a simple HTTP server:
> ```bash
> cd frontend
> npx serve .
> # Then visit http://localhost:3000
> ```

## 🌐 API Endpoints

| Method | Endpoint                    | Description                              |
|--------|-----------------------------|------------------------------------------|
| GET    | `/`                         | Health check                             |
| POST   | `/api/level1/save`          | Save player progress to database         |
| GET    | `/api/level1/progress`      | Fetch all entries (filter by ?username=) |
| GET    | `/api/level1/leaderboard`   | Top 10 players by highest score          |

### POST `/api/level1/save` — Request Body

```json
{
  "username": "AgentZero",
  "levelCompleted": true,
  "score": 60
}
```

### POST `/api/level1/save` — Response

```json
{
  "success": true,
  "message": "Level 1 progress saved successfully!",
  "data": {
    "_id": "...",
    "username": "AgentZero",
    "levelCompleted": true,
    "environmentFile": "development",
    "score": 60,
    "timestamp": "2024-01-01T00:00:00.000Z"
  }
}
```

## 🗄️ Database Schema

Collection: `level1progresses`

| Field           | Type    | Description                          |
|----------------|---------|--------------------------------------|
| username        | String  | Player's chosen name (2–30 chars)    |
| levelCompleted  | Boolean | Whether the level was finished        |
| environmentFile | String  | Value from ENVIRONMENT in .env        |
| score           | Number  | XP earned (0–60)                     |
| timestamp       | Date    | When the record was created           |
| createdAt       | Date    | Auto-generated by Mongoose            |
| updatedAt       | Date    | Auto-generated by Mongoose            |

## 🛠️ Troubleshooting

**"MongoDB connection failed"**
→ Make sure MongoDB is running: `mongod` (local) or check Atlas network access settings.

**"Failed to save — is the backend running?"**
→ The frontend can't reach the backend. Make sure `npm start` is running in the `backend/` folder.

**CORS errors in the browser console**
→ The `cors` package is already configured in `server.js`. If you're serving the frontend from a different port, it should work out of the box.

**Port already in use**
→ Change `PORT=5000` to another port in `.env`, and update `API_BASE` in `frontend/index.html` accordingly.

## 🎮 How to Play

1. Enter a username on the title screen
2. Use **Arrow Keys / WASD** to move your agent
3. Walk near objects and press **ENTER** or click them
4. Answer the cybersecurity questions correctly to earn XP
5. Complete all 3 zones, then reach the EXIT door
6. Your progress is automatically saved to MongoDB when you finish!
