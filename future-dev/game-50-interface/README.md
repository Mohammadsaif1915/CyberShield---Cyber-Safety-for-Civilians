# Cyber Defense 50-Level Interface

This folder is a preserved future-development copy of the game hub.

- Active production hub: `client/public/game-app`
- Future 50-level interface: `future-dev/game-50-interface`
- Levels 1-5 are wired to playable level files.
- Levels 6-50 are placeholder mission nodes for future development.
- Progress is stored separately in localStorage under `cd_levels_future_50`.

Open `index.html` directly in a browser to preview the interface.
